# Waymate

A rounded W follows a walking route between two companion points. The mark uses simple vector geometry and stays legible at launcher size. It has no gender-specific imagery.

- Navy: `#143A50`
- White: `#FFFFFF`
- Mint on navy: `#79DFBF`
- Green on a light background: `#27876D`

Use [the app icon](waymate-icon.svg) for square placements and [the transparent mark](waymate-mark.svg) beside the Waymate name. Keep clear space equal to an endpoint dot on every side. The Android adaptive icon keeps the complete mark within its safe circle, and includes a monochrome variant for themed icons.

The vector source is original to this project. It uses no stock artwork, generated bitmap or external logo asset.

The installed Android application ID and existing storage keys retain their original identifiers so upgrading preserves contacts, sessions, journeys and pending alerts. All displayed branding uses Waymate.
