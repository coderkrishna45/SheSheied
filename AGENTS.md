# Phone connection

The user explicitly requires the running HTTPS trycloudflare API URL for physical-phone use. Keep the phone's saved backend URL and the APK build default aligned with `PUBLIC_BASE_URL` in `api/.env`. Do not switch the app to USB reverse forwarding, localhost, or the Android emulator host. A USB cable may be used to install an APK or inspect the device; app requests must use the public tunnel. Preserve saved sessions, Circle contacts, history and active journeys when updating connection settings.
